# Bike Sales Analysis – Excel Dashboard

## Project Overview
This project focuses on analyzing bike sales data using Microsoft Excel to identify customer purchasing patterns and understand the factors influencing bike purchases.

The goal of this project is to transform raw data into meaningful insights through data cleaning, data analysis, Pivot Tables, and interactive dashboard visualizations.

## Tools & Technologies
- **Microsoft Excel**
- Pivot Tables
- Excel Functions
- Data Cleaning
- Data Visualization
- Interactive Slicers

## Dataset
The dataset contains customer demographic and purchasing information, including:
- Gender
- Age
- Income
- Marital Status
- Education
- Occupation
- Commute Distance
- Region
- Bike Purchase Status

## Project Steps

### 1. Data Cleaning
- Removed duplicate records.
- Standardized inconsistent data entries.
- Created an age bracket column to categorize customers.
- Prepared the dataset for analysis.

### 2. Data Analysis
- Created Pivot Tables to summarize bike purchases.
- Analyzed purchasing patterns across different customer demographics.
- Compared bike purchases based on income, age, gender, and commute distance.

### 3. Dashboard Creation
- Developed an interactive Excel dashboard.
- Used charts to present key findings.
- Added slicers to filter results dynamically.
- Organized visualizations to make insights easy to understand.

## Key Insights
The dashboard helps explore:
- Bike purchasing patterns across different age groups.
- Differences in purchasing behavior by gender.
- The relationship between customer income and bike purchases.
- How commute distance relates to purchasing decisions.
- Regional differences in bike purchasing behavior.
